# ATM-WALLET

Your Money, Your Way.

ATM Wallet is a simple and secure digital wallet application that allows users to check their balance, deposit money, withdraw money, and view their transactions - all in one place.
Built for everyday use, with a bold and modern design.


 FEATURES
 View Balance in real-time
 Deposit Money
 Withdraw Money
 Transaction History
 Fast and Easy to Use Interface
Clean Dull + Bright Orange Design.
